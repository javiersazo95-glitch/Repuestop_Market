# 20-oct (opcion A): se indexaban solo las paginas institucionales mientras se
# captaban tiendas. 10-nov: con productos reales publicados se abren tambien el
# catalogo, las fichas de repuesto y las fichas de tienda. Cada ficha trae su
# descripcion, canonical y datos de producto (src/routes/pageSeo.js) y el backend
# arma su sitemap (/sitemap-catalogo.xml, ver vercel.json).
#
# Google aplica la regla mas especifica (la mas larga): "Allow: /$" abre solo
# el inicio y "Disallow: /" cierra todo lo demas, asi que lo privado (perfil,
# carrito, checkout, compra) sigue cerrado sin listarlo. Las combinaciones de
# filtros del catalogo (?categoria=...&marca=...) son infinitas y repiten las
# mismas fichas: "Disallow: /repuestos?" es mas larga que "Allow: /repuestos" y
# las deja fuera. Los archivos de /assets y las imagenes se abren porque Google
# necesita el JavaScript para ver la pagina.
#
# PENDIENTE: talleres y fallas siguen cerrados hasta decidir su indexacion.
# ==========================================================================
